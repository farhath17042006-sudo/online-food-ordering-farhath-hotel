# Farhath Hotel - Online Food Ordering System
A web-based food ordering system converted from a Tkinter desktop application.

## Features
- Menu display from SQLite database
- Add to cart, adjust quantities, remove items
- Checkout and bill generation
- Responsive design for mobile and desktop

## Local Installation
1. Install dependencies:
   `pip install -r requirements.txt`
2. Run the application:
   `python app.py`

## Render Deployment
1. Connect this repository to Render.
2. Build Command: `pip install -r requirements.txt`
3. Start Command: `gunicorn app:app`
render live link : https://online-food-ordering-farhath-hotel.onrender.com
